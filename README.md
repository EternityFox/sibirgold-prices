# sibirgold-prices

Актуальные цены скупки радиодеталей для страниц категорий сайта https://sibirgold.ru/.
Файлы обновляются автоматически раз в сутки. Вручную их не редактируйте.

- `index.json` — список категорий и время их обновления.
- `<категория>.json` — цены категории, например `diody.json` для https://sibirgold.ru/diody/.

```json
{
  "schema": 1,
  "category": "diody",
  "updated": "2026-10-13T06:50:12+10:00",
  "currency": "RUB",
  "items": [
    { "id": "2a510b-i-podobnye", "name": "2А510Б и подобные", "image": "/img/47361003_1920_q70.jpg",
      "unit": "шт", "new": 36.77, "used": 29.42 },
    { "id": "diod-d229-massa-35-g", "name": "Диод Д229", "desc": "Масса: 3,5г.", "image": "/img/47361165_1920_q70.webp",
      "unit": "кг", "price": 162.0 },
    { "id": "krupnye-fotodiody", "name": "Крупные фотодиоды", "image": "/img/47361325_1920_q70.webp", "price": null }
  ]
}
```

`name` — название, `desc` — подпись (может отсутствовать), `image` — путь к фото на sibirgold.ru
(может отсутствовать — фото ещё не добавлено).

`new` и `used` — цены за новые и б/у, `price` — единая цена, `price: null` — цена договорная.
Цены в рублях за единицу `unit`. Время — по Владивостоку (UTC+10).
